# 同梱サンプル画像

`parcel_ja.png` は、本プロジェクトの評価・デモ用に Pillow で描画した独自の合成画像です。第三者の写真は使用していません。名前・住所・電話番号は架空であり、実在の配送ラベルや個人情報ではありません。`parcel_ja.json` は対応する評価用の正解データです。

camereon のアプリ・評価・デモでの表示、黒塗り等の加工、加工結果の保存、APK への同梱配布に利用するために作成しています。フォントファイルは同梱していません。

アプリでは起動画面の「サンプルで試す」から開きます。カメラや AI モデルがなくても、実際の編集・保存の流れを試せます。

サンプルも通常の写真と同じ日本語OCRで読み取り、住所を要素ごとの候補として最初から隠します。
枠をタップすると個別に解除・再適用でき、「取り消す」で直前の選択へ戻せます。
「保存前に確認」→「写真に保存」で、その時点で選択した範囲だけを加工して保存します。
以前の固定座標の仮候補は通常のサンプル画面では使用しません。
