## 確認内容

全290件のFlutterテストと静的解析が成功。実OCRによる電話端末テスト2件、既存住所端末テスト1件も成功した。電話の2件は機内モード有効、Wi-Fi・モバイルデータ無効、Active default network: noneの状態で実行し、終了後は元の通信設定へ戻した。

合成画像では電話4件が自動選択、7〜8桁のラベル付きローカル番号2件が未選択候補になった。タップでの解除／再適用、任意候補の選択と取り消し、確認画面、写真ライブラリへの保存を実行した。保存JPEGの画素を、OCR枠とは独立した元の描画座標で検査し、番号全体が消えることを確認した。画像サイズは1200×1080を維持した。

通常の郵便番号は黒塗りされ、未選択の短い番号・管理番号・日付・英語の氏名の値は残った。既存住所辞書は「電話番号」「管理番号」などの一部を地名として拾うため、これらのラベルは住所候補として隠れる場合がある。この既存挙動は今回変更していない。住所端末テストも、地名と一致する日本語氏名の既存誤検出を避けるため英語の氏名を使用した。

この結果は既存サンプルと合成画像に対する動作検証であり、一般実写写真での精度やiOS動作を保証しない。番号の実際の割り当て・通話可能性は検証しない。

## 配布ビルド

Android arm64のrelease APK作成も成功した（Flutter表示50.1MB）。端末テスト直後に`--no-pub`を付けてreleaseビルドすると、テスト用プラグインの生成登録情報が残りコンパイルが失敗したため、通常の`flutter build apk --release --target-platform android-arm64`で再生成して成功した。依存設定・ロックファイルは変更していない。release APKの端末上での追加動作確認は未実施。
