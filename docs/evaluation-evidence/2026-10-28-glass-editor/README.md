# 写真中心のガラス調UI

`editor.gif` と `selected.png` は、Android 12 ARM64エミュレーターへ通常のDebug APKを導入し、1080×1920の縦画面で撮影した。GIFは実録画を360×640・12fpsへ縮小したもの。

表示している配送ラベルは[本プロジェクトの合成サンプル](../../../tools/vlm-eval/fixtures/README.md)。名前・住所・電話番号は架空で、ユーザー提供の実写や顔の評価fixtureは含まない。

自動検出、光のスキャン、候補枠の出現、名前・住所の枠をタップした黒塗りを確認できる。実機の画質・速度の評価記録ではない。検証項目は[検出器の統合](../../detection-integration.md)を参照。
